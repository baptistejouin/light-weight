# Stack

This project was started as a side project to learn SolidJS, very similar to React by design but with some design changes made for performance and a better development experience, so I just wanted to give it a try. I also need a gym app tailored for my needs, so it's a solid decision.

This project is volontary made for mobile usage and will be available as PWA

## Developing
```bash
pnpm i
pnpm run dev
 
# optional database UI
pnpm studio
```

Web UI available at `https://local.drizzle.studio` for the database at `./drizzle/db.sqlite`

## Goals
- strong visual identity
  - https://fonts.google.com/specimen/Bitcount+Single
- support running / gym
- add strava connection for running sync
- simple but nice week/month/year analysis and history
- simple data record (in during the session live)
- support multiple gym type of training (pyramid...)
- user and account support (simple connect button with classic provider github/google?)
